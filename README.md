📌 Student Task Manager

A simple and beginner-friendly Task Manager web application built using HTML, CSS, and JavaScript.
This project helps users add, complete, and delete daily tasks, and saves data using LocalStorage.

⸻

📂 GitHub Repository

👉 https://github.com/suchipatel03/student-task-manager

⸻

🛠️ Tech Stack
•	HTML5
•	CSS3
•	JavaScript
•	Browser LocalStorage

⸻

✨ Features
•	➕ Add new tasks
•	✅ Mark tasks as completed / uncompleted
•	❌ Delete individual tasks
•	🧹 Clear all tasks
•	💾 Tasks persist using LocalStorage
•	⌨️ Press Enter to add a task
•	📱 Responsive design
	
⸻

🧠 What I Learned
•	DOM manipulation using JavaScript
•	Event handling (click, keydown)
•	Using LocalStorage for data persistence
•	Structuring a basic web project

⸻

🧪 How to Run Locally
1.	Clone the repository:
			git clone https://github.com/Suchipatel03/student-task-manager.git
			
2.	Open the project folder
3.	Double-click index.html
OR open with Live Server in VS Code
